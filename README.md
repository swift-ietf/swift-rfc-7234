# swift-rfc-7234

> **Status: Namespace-reservation** — This package reserves the RFC 7234 namespace. RFC 7234 (HTTP/1.1 Caching) was obsoleted by RFC 9111; its caching semantics are consolidated into HTTP Semantics/Caching and implemented in swift-rfc-9111. The package currently exposes only an empty `RFC_7234` namespace enum and is not independently implemented.
